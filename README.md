# 非线性音频系统的数字建模与系统辨识

**[在线阅读 00—06 完整合订版](https://excillex-marisa.github.io/volterra-wiki/)** · **[下载完整 Markdown](downloads/Volterra_Wiki_00-06_完整合订版_GitHub图床.md?raw=true)**

本书以音频工程师熟悉的线性卷积为起点，先回顾 Volterra 理论从泛函走向核辨识的历史，再进入非线性算子与历史记忆，并讨论与神经网络的理论交汇、白盒与唯象建模、概率统计、物理约束及实时约简。核心目标是建立一套能从真实音频硬件测量、训练和验证中使用的数学与工程知识体系。

## 教学路线与进阶分流

全书保持 00—06 的固定章节顺序，正文保留原有数学推导与证据。首次学习建议沿 **00 基础语言 → 01 Volterra 核 → 02 神经网络训练 → 03 混合架构与验证 → 06 商业案例** 的核心线阅读；需要研究核的严格逼近、随机辨识或复杂动力学时，进入 **04 高级理论**；需要研究电路、空间场数值求解及实时代理时，进入 **05 物理计算**。04、05 是互补的深入路线，也可以在阅读 03 和 06 时按问题回查。

每章开头均标明核心学习部分与选读的进阶专题，避免首次阅读时被高级公式打断。第 01 章完整保留 ESS/Novák 精确核反解、多方差辨识、各类核约简与 ADAA 推导；第 03 章强调架构选择与可操作测量，第 04、05 章分别补充严谨的数学假设与物理计算依据。读者可以在理解完整问题图景后逐步深入。

**第 02 章新教学顺序：** 2.1—2.6 通用机器学习基础，2.7—2.9 音频机器学习，2.10—2.19 音频处理器神经数字建模，2.20—2.27 Volterra 与神经网络的双重系统辨识。保留现有四张 02 章 SVG；本轮暂不制图。

## 分章阅读

- [00 前置概念与术语约定](00_前置概念与术语约定_图文版.md)：从混音母带常见的“厚、糊、破”等听感出发，用纯音解释 H1/H2/H3、谐波结构、波形对称性与奇偶次谐波；再通过平方、立方、Taylor 展开及第一类 Chebyshev 多项式认识失真生成机理，补充 THD、互调、次谐波和混叠的测量直觉。随后建立线性与非线性、记忆与状态、卷积、泛函和必要数学符号的共同基础，并通过 DAW 示例与章节自检进入 Volterra。
- [01 Volterra 级数](01_Volterra级数_图文版.md)：从历史、Volterra 核与交叉记忆进入系统辨识，先以音频处理模块和测量情境介绍 Hammerstein、Wiener、Wiener–Hammerstein、Hammerstein–Wiener，再推导各自等效核；进阶线保留 ESS/Novák 反解、多方差辨识、核约简、收敛与 ADAA。
- [02 从 Volterra 到神经网络](02_从Volterra到神经网络_模型辨识与NAM.md)：神经网络与非线性系统辨识的交叉史、固定核回归、WaveNet、LSTM、NAM、参数超网络、可微分 DSP 与储备池计算。
- [03 混合建模、训练边界与实时约简](03_混合建模训练边界与实时约简.md)：以测量目标和实时预算决定短时核、物理状态与神经模型的职责，保留 Laguerre–Volterra、Play、ADAA、NARX/NOE 及光电压缩器架构案例。
- [04 高级系统辨识：非线性算子、衰减记忆与随机正交展开](04_高级系统辨识_非线性算子与混沌分解.md)：三条可选研究路线：泛函可微性与衰减记忆、Koopman/Carleman 与长尾状态、Wiener Chaos/PCE 与 Fisher 信息。
- [05 物理约束、模型降阶与神经代理](05_物理约束与实时代理建模.md)：先理解电路 DAE、MNA、DK/WDF，再拓展到空间场 FEM/POD/DEIM，最终研究神经代理、物理残差与离线蒸馏。
- [06 Acustica Audio 技术发展史](06_Acustica_Audio技术发展史_含NOVA与商业建模案例.md)：从核测量到商业插件的历史桥梁、Nebula、VVKT、NAT、Acqua、NOVA，以及 YELLOW、SKY、SNOW 的商业技术案例。

## 本版选题边界

高级数学内容需要直接服务于非线性音频系统的输入输出辨识、状态建模、物理求解、参数不确定性或实时计算。Koopman 与 Carleman 按状态辨识与模型约简讨论；分数阶微积分按衰减记忆讨论；Wiener Chaos Decomposition 和 Polynomial Chaos Expansion 按随机泛函、器件公差与统计辨识讨论。

## 工程研究原则

每个新模型均明确研究对象、数学假设、音频可测现象、实时实现与失效条件。训练集和测试集分离，报告时间对齐、采样率、状态初始化、计算成本及参考硬件来源。厂商公开的技术定义、模型结构实例、实测输入输出行为及本书提出的等效数学解释分别约束其适用范围。

## 仓库结构与文件职责

仓库只保留一个主入口：本页 README.md。分章正文、发布合订版、配图和维护工具各有固定位置：

- README.md：唯一入口与阅读导航。
- 00—06 七篇分章 Markdown：正文维护源。
- downloads/：唯一完整合订版，也是在线阅读器的构建输入。
- figures/：39 张 SVG 教学图。
- docs/EDITORIAL_GUIDE.md：编辑与公式规范。
- docs/revisions/：修订记录及索引。
- tools/reader/：在线阅读器构建程序。
- tools/validate_sources.py 与 tools/figure_manifest.txt：公式围栏、章节链接、39 张 SVG 清单及 XML 完整性验证。
- tools/check_github_math.py：GitHub 原生公式预览检查（受网络响应影响，CI 中作为非阻断检查）。
- .github/workflows/reader.yml：GitHub Pages 自动构建与发布。

分章文件使用相对路径引用 figures/*.svg，方便在仓库内逐章阅读；合订版统一使用 GitHub Raw 图片链接，保证从 downloads/ 打开时图片路径仍然有效。在线阅读器从合订版生成，并在构建时核对七篇分章内容与全部 39 张图片。不要在根目录另放一份与下载合订版同名的导航文件；阅读导航统一维护在本页。
