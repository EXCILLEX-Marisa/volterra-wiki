> Volterra Wiki · 中文开放教材 · 2026-11-13 高级理论扩充版

## 本版选题边界

高级数学内容需要直接服务于非线性音频系统的输入输出辨识、状态建模、物理求解、参数不确定性或实时计算。Koopman 与 Carleman 按状态辨识与模型约简讨论；分数阶微积分按衰减记忆讨论；Wiener Chaos Decomposition 和 Polynomial Chaos Expansion 按随机泛函、器件公差与统计辨识讨论。与上述目标关联较弱的确定性混沌系统、吸引子、Lorenz、Lotka–Volterra 及实验性复杂物理声音生成暂不收录。

## 工程研究原则

每个新模型均明确研究对象、数学假设、音频可测现象、实时实现与失效条件。训练集和测试集分离，报告时间对齐、采样率、状态初始化、计算成本及参考硬件来源。厂商声明、静态逆向材料、文献定理与本书提出的研究假说分开表达。
