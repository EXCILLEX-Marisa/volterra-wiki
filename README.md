# 非线性音频系统的数字建模与系统辨识

> Volterra Wiki · 面向音频工程的开放中文技术教材 · 2026-11-13 审订版

本项目从音频工程师熟悉的线性卷积入手，以 Volterra 级数解释非线性记忆和输入历史之间的交互，再延伸到系统辨识、神经网络、物理白盒、唯象学状态建模与实时混合架构。Volterra 是进入这套知识体系的数学入口，整套 Wiki 讨论的是**非线性音频系统建模的方法、适用范围、辨识实验与工程实现**。

- [00 前置概念与术语约定](00_前置概念与术语约定_图文版.md)：卷积、线性与非线性、记忆与状态、收敛与发散、Taylor 展开、切比雪夫基、感受野、优化与泛化。

- [03 混合建模、训练边界与实时约简](03_混合建模训练边界与实时约简.md)：Laguerre–Volterra、物理与唯象状态、ADAA/过采样、NARX/NOE 自由运行和 Test Bench。
- [04 Acustica Audio 技术发展史](04_Acustica_Audio技术发展史_含NOVA与逆向证据.md)：Nebula、VVKT、NAT、Acqua、NOVA 和 SKY 的技术演进及证据层级。
- [00—04 完整合订版（GitHub 图床）](Volterra_Wiki_00-04_完整合订版_GitHub图床.md)

## 本轮审订重点

全书将先行定义概念、再陈述运算机理和适用条件的教材文风作为主线，减少反问与否定对照句式，集中说明厂商技术声明与真实系统辨识证据的关系。03 的新增内容包含 Laguerre 正交基位置、分支抗混叠、状态自由运行约束、六组黑盒测试协议；02、03、04 增补 DOI、arXiv 和官方开源项目入口。具体测试及模拟结果仍需独立实验获得，文中测试表为可复现实验设计。
