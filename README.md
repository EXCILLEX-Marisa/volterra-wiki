# 非线性音频系统的数字建模与系统辨识

本书以音频工程师熟悉的线性卷积为起点，沿 Volterra 级数进入非线性算子与历史记忆，再讨论神经网络系统辨识、白盒与唯象建模、概率统计、物理约束及实时约简。核心目标是建立一套能从真实音频硬件测量、训练和验证中使用的数学与工程知识体系。

## 本版选题边界

高级数学内容需要直接服务于非线性音频系统的输入输出辨识、状态建模、物理求解、参数不确定性或实时计算。Koopman 与 Carleman 按状态辨识与模型约简讨论；分数阶微积分按衰减记忆讨论；Wiener Chaos Decomposition 和 Polynomial Chaos Expansion 按随机泛函、器件公差与统计辨识讨论。

## 工程研究原则

每个新模型均明确研究对象、数学假设、音频可测现象、实时实现与失效条件。训练集和测试集分离，报告时间对齐、采样率、状态初始化、计算成本及参考硬件来源。厂商声明、静态逆向材料、文献定理与本书提出的研究假说分开表达。
