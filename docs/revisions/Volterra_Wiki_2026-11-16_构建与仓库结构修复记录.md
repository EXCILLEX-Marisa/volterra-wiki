# Volterra Wiki 构建与仓库结构修复记录

**日期：2026-11-16**

## 问题定位

GitHub Actions 的 Run #26（commit d630980）在阅读器构建阶段失败。日志中的直接错误为：

```text
Figure count mismatch: repository 37, preview 18.
```

检查发现，合订版的 37 张配图混用了两种路径：18 张使用 GitHub Raw 链接，19 张使用相对路径。阅读器构建程序只识别 GitHub Raw 链接，因此只收集到 18 张图片，随后因图片数量不一致而中止。此前连续失败的构建均由这一问题触发；中间的 Cancelled 运行则是后续 push 触发并发策略后取消旧运行，不属于额外的编译错误。

## 修复内容

1. 将合订版全部 37 张图片统一为 GitHub Raw 链接，保持独立分章继续使用相对路径。
2. 清理合订版中逐章阅读链接与分章导航行，章节目录由在线阅读器统一提供。
3. 在阅读器构建程序中增加七篇分章与合订版的内容一致性检查。
4. 将图片完整性检查从单纯数量比较改为文件名集合核对，能够分别报告缺失文件与未引用文件。
5. 将公式检查脚本的导航目标统一到 README.md 与 downloads/ 合订版路径。
6. 删除根目录与下载合订版同名的重复导航文件。README.md 已包含在线阅读、下载和七篇分章入口，因而不损失导航功能。
7. 新增本目录的修订记录索引，集中整理历史记录。

## 内容核对

修复前已逐章比较分章正文与合订版。去除分章专用的在线阅读链接、章节导航，并将图片路径归一化后，00—06 七章正文均一致。全部 37 张图片引用均能对应到仓库中的唯一 SVG 文件。

## 发布验证

本记录在修复提交后补充 GitHub Actions 的最终构建结果。只有在新的阅读器构建与 Pages 发布均成功后，才将本轮状态标记为完成。
