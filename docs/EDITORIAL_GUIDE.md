# Volterra Wiki 编辑与公式维护规范

本文件供后续章节作者及校对人员使用，不作为《00》前置概念的一部分。全书采用面向音频工程师的中文教材叙事：概念从实际问题引出，数学定义、实验依据与工程能力边界在首次用到时展开。

## 知识结构与叙述

- **00 只讲共同前置知识**：离散信号、系统性质、记忆与状态、卷积、泛函直觉、模型结构和全书基本符号。
- **01—06 按问题逐层增加数学深度**：01 从理论史、核表示与辨识讲起；02 讨论训练与神经模型；03 讨论混合架构和实验；04 严格展开算子与统计理论；05 讲物理求解和实时计算；06 研究商业技术史与应用。
- 介绍一个新概念时，优先采用“现象或实验 → 需要的新数学工具 → 表达与推导 → 可测量结果 → 工程适用条件”的顺序。对于同一概念，首次出现处完成必要铺垫，后续章节通过链接深化，避免多次从头定义。
- 语言自然、准确、信息密度高。减少成段的“不是……而是……”“不能证明……”“并不意味着……”等防御性表达；只有数学条件、辨识证据、产品内部结构归因等确实需要时才保留限定。避免一句话独占一段、营销式强调及过激判断。
- 公式、文献标号、SVG 相对路径和跨章链接属于正文的一部分。文字调整时同步维护公式语义、图注、引用与章节编号。

## GitHub 数学排版约定

本书使用 MathJax 和 GitHub Markdown。行内公式采用美元符号加反引号形式，例如 $`x[n-1]`$。此写法可避免下划线、方括号与反斜杠被 Markdown 优先解析，也适用于表格单元格。

独立数学公式使用单独成行的 math 围栏；公式正文保持未经 Markdown 转义的 LaTeX，前后留空行：

```math
y[n]=\sum_{k=0}^{M-1}h[k]x[n-k].
```

多行公式在围栏内部使用 \begin{aligned}...\end{aligned}。列表中的复杂数学块宜在列表之外单独成段；表格中的绝对值与范数用 \lvert、\rvert、\lVert、\rVert 避免竖线被当作列分隔符。

编辑后至少进行四项检查：公式的闭合与渲染、Markdown 表格解析、图片路径有效性、读者视图中的长公式与引用显示。仅检查美元符号数量或大括号配对，无法保证真实渲染成功。

## 合订版和发布

七篇分章是维护用正文；下载文件 downloads/Volterra_Wiki_00-06_完整合订版_GitHub图床.md 是在线阅读器的构建输入。根目录同名文件是指向阅读器与分章的导航页。每轮修改要同步更新下载合订版、README 的阅读说明和配图分布。

在线阅读器由 tools/reader/build.mjs 从 downloads/ 中读取 Markdown 并构建。GitHub Actions 在提交主分支后发布 GitHub Pages；PR 构建可作为公式解析与资源完整性的非回归检查。
