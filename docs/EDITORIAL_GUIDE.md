# Volterra Wiki 编辑与公式维护规范

本文件供后续章节作者及校对人员使用，不作为《00》前置概念的一部分。全书采用面向音频工程师的中文教材叙事：概念从实际问题引出，数学定义、实验依据与工程能力边界在首次用到时展开。

## 知识结构与叙述

- **00 只讲共同前置知识**：离散信号、系统性质、记忆与状态、卷积、泛函直觉、模型结构，以及覆盖代数、微积分、线性代数、信号变换、函数空间、概率统计和优化的全书符号与运算索引。符号索引还应区分测量值、参考值、理想值、预测值与参数估计值，解释数学期望和样本均值、上下标与修饰符，并为张量维度、张量阶数与秩、多重求和、阶乘、组合数和大 O 复杂度提供可读的入门说明；物理量纲、单位、无量纲化与数据归一化的区别，以及齐次性、自由度、可辨识性、病态等跨章术语，也应在 00 给出初步直觉。
- **00.2 的非线性音频入门**：以纯音、谐波结构、波形对称性和静态 Waveshaper 作为工程师理解非线性理论的第一道桥梁；讲解平方与立方的谐波贡献、Taylor 局部展开和第一类 Chebyshev 多项式的归一化单音选阶，解释互调、次谐波、混叠及相对谐波测量。01 再研究多维核和交叉记忆；不得把已在 00 完整铺垫的基础定义全部重复放回 01。
- **01—06 按问题逐层增加数学深度**：01 从理论史、核表示与辨识讲起；02 讨论训练与神经模型；03 讨论混合架构和实验；04 严格展开算子与统计理论；05 讲物理求解和实时计算；06 研究商业技术史与应用。
- **核心线与研究线分流**：01 首次阅读建立核、交叉记忆、测量范围、约简与能力边界；精确 ESS 反解、多方差辨识、收敛、ADAA 等完整推导保留在原位置并标为进阶。02 的超网络、DDSP、ESN 属专项拓展；03 负责行为观察、模型组合和实验协议；04 与 05 分别负责理论成立条件及物理计算，作为可按需深入的并行路线。
- **核表示与工程约简区分**：标准单输入 Volterra 核的置换对称化消除重复坐标，保留相同的输入—输出映射；唯一单项式回归需处理多项式重数因子。对角、带状、稀疏及低秩等约简进一步引入结构假设；讨论资源时分别说明独立系数数量、存储组织及实际每采样运行开销。
- **块结构名称固定**：Hammerstein 为 N–L，Wiener 为 L–N，Wiener–Hammerstein 为 L–N–L，Hammerstein–Wiener 为 N–L–N。单一 Hammerstein 共享一条线性滤波器，并行 Hammerstein 允许各阶独立滤波器；解释这些结构需覆盖信号流、等效 Volterra 核、可辨识性与音频抗混叠边界。
- **跨章案例明确职责**：03 的光电案例用来比较架构，05 的光电案例用来解释物理求解与神经修正，06 的商业案例用于核对公开资料、资源与推论证据。首次出现高级对象时注明深入章节，避免读者必须先掌握尚未介绍的数学细节。
- **图片图注一致性**：正文图片必须紧跟正确编号的图注，图注编号应与 SVG 文件名中的 `章节-图号` 相符，且在同章中依正文顺序递增；图片归属、文件名、实际显示次序都应纳入静态检查。
- 基础求和、连乘与多重求和首次出现时应给出可逐项计算的小型数值实例，解释索引、上下限、展开过程及其与离散音频历史项的对应关系；公式索引不能替代初学者的阅读教学。
- 00 章抽象系统或运算首次出现时应就地建立简明计算例子；章节结尾给出可复述或可手算的检查点。0.8 作为分层查阅索引使用，避免要求初学者一次掌握全部高级记法。
- 介绍一个新概念时，优先采用“现象或实验 → 需要的新数学工具 → 表达与推导 → 可测量结果 → 工程适用条件”的顺序。对于同一概念，首次出现处完成必要铺垫，后续章节通过链接深化，避免多次从头定义。
- 语言自然、准确、信息密度高。减少成段的“不是……而是……”“不能证明……”“并不意味着……”等防御性表达；只有数学条件、辨识证据、产品内部结构归因等确实需要时才保留限定。避免一句话独占一段、营销式强调及过激判断。
- 公式、文献标号、SVG 相对路径和跨章链接属于正文的一部分。文字调整时同步维护公式语义、图注、引用与章节编号。
- 全书符号以 00.8 为默认索引；章节可定义局部符号，但首次出现时必须解释。重点区分实际／测量／参考／理想／预测值、期望与样本均值、估计参数与最优参数、变量下标与文字下标、张量阶数与秩；并区分完整多维 Volterra 核与对角支路核、Volterra 核与 Wiener 核、Fréchet 与 Gâteaux 导数、Dirac 与 Kronecker delta，以及卷积、函数复合、Hadamard 积和张量积。

- **逐步推导与数值运算**：重要公式首次出现时，明确已知量、未知量、适用条件及相邻公式的关键变换。核心公式至少配一个可手算的数值例子，给出代入、中间结果、输出或残差及工程解释。区分正向计算、数学推导与参数反求；复用贯穿案例，后文引用深化。章节自检应含计算题与可核对解答。高级证明可放在进阶部分，避免在 00 堆积专项定理。教学数值须与真实测量数据明确区分。

## GitHub 数学排版约定

本书使用 MathJax 和 GitHub Markdown。行内公式采用美元符号加反引号形式，例如 $`x[n-1]`$。此写法可避免下划线、方括号与反斜杠被 Markdown 优先解析，也适用于表格单元格。

独立数学公式使用单独成行的 math 围栏；公式正文保持未经 Markdown 转义的 LaTeX，前后留空行：

```math
y[n]=\sum_{k=0}^{M-1}h[k]x[n-k].
```

多行公式在围栏内部使用 \begin{aligned}...\end{aligned}。列表中的复杂数学块宜在列表之外单独成段；表格中的绝对值与范数用 \lvert、\rvert、\lVert、\rVert 避免竖线被当作列分隔符。

编辑后至少进行五项检查：公式的闭合与渲染、Markdown 表格解析、图片路径有效性、七篇分章与合订版内容一致、读者视图中的长公式与引用显示。合订版中的 39 张 SVG 必须全部使用仓库 main 分支的 GitHub Raw 链接；分章文件则使用相对路径。仅检查美元符号数量或大括号配对，无法保证真实渲染成功。
